# 拾页 · 高中知识点网站

一屏铺开的知识图谱 + 亲手搭建的学习工作台。核心是三句话：**看得懂、看得清、看得不乱**。

本地优先，断网可用。整个网站就是一堆 HTML / CSS / JS，双击 `index.html` 就能打开。

## 这套东西的核心机制

学习发生在**你和 AI 的对话里**：你讲、它追问三层（凭什么 / 举例 / 反例）、卡住就停在那、隔天拿你自己的话反问你。

网站只做三件事：

1. **工作台**（`workbench.html`）：你亲手把教材原文拆成节点，起名、连线、写理由。
2. **留下你的原话**：点亮"真懂"之前，必须用你自己的话写一句（≥8 字，不许抄书）——这是隔天回访的弹药。
3. **到期反问**（`review.html`）：隔天/隔几天，网站把那句话摆出来，你自己判讲不讲得出。讲不出就退回红色，重新建。

一句话：**你不是在学完以后把结果登记进网站，你是在网站上亲手把知识搭出来——搭的过程就是学的过程。**

## 文件

- **`index.html`** — 首页
- **`workbench.html`** — 学习工作台（三栏一屏：原文卡 → 画布 → 三问）
- **`review.html`** — 复习队列。显示工作台点亮的块 + 错题标记，按到期时间回访
- **`subjects/math/map.html`** — 数学·集合章知识图谱（一屏铺开，节点 + 连线）
- **`subjects/math/set.html`** — 教材帮 P001「1.1 集合的概念」真实内容
- **`shared/store.js`** — 统一账本 `shiyue_v2`，工作台/复习/错题一个 key 管，自动迁移旧数据
- **`shared/`** — 样式和脚本（蓝色科技风、图谱渲染器、导航）
- **`tools/`** — 手机传照片工具（局域网原图上传，不压缩、不联网）
- **`docs/参考_拾页文档包v1/`** — 另一 Agent 写的机制文档。**参考，不是规矩**，先看里面的「先看我.md」

## 设计原则

1. 事实以教材原文为准；书上没有的不编，只记名字并标注"等拍到下一页"。
2. 学习 = 亲手搭建。判断权归学习者，网站只负责落地和挑刺。
3. 考核是软的（你自己判讲不讲得出），流程是硬的（不写原话就点不亮）。
4. 照片等隐私文件只留本地，不进这个仓库（见 `.gitignore`）。

## 数据

存在浏览器本机 `localStorage`，key 是 `shiyue_v2`。清缓存 / 换浏览器 / 换电脑前，先在复习页点「导出我的数据」存一份 JSON。
