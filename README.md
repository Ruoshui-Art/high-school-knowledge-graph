# 高中知识点网站

一屏铺开的知识图谱 + 亲手搭建的学习工作台。核心是三句话：**看得懂、看得清、看得不乱**。

本地优先，断网可用。整个网站就是一堆 HTML / CSS / JS，双击 `index.html` 就能打开。

## 目前有的东西

- **`index.html`** — 首页入口
- **`workbench.html`** — 学习工作台（样板）。左边是教材原文卡，拖到中间画布变成节点，自己起名、连线、写理由、判断"真懂还是只记名字"。节点按掌握程度着色，真懂的节点隔天进复习队列。
- **`subjects/math/map.html`** — 数学·集合章知识图谱（一屏铺开，节点 + 连线）
- **`subjects/math/set.html`** — 教材帮 P001「1.1 集合的概念」真实内容
- **`review.html`** — 复习队列（空架子，等工作台跑起来后接上）
- **`shared/`** — 样式和脚本（蓝色科技风、图谱渲染器、用户块、导航）
- **`tools/`** — 手机传照片工具（局域网原图上传，不压缩、不联网）

## 设计原则

1. 事实以教材原文为准；书上没有的不编，只记名字并标注"等拍到下一页"。
2. 学习 = 亲手搭建。判断权归学习者，网站只负责落地和挑刺。
3. 照片等隐私文件只留本地，不进这个仓库（见 `.gitignore`）。

## 状态

持续搭建中。知识工作台目前是可用样板，还在根据实操反馈迭代。
