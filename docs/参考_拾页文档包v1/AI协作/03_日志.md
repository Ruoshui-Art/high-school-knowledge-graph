# 03 · 学习日志（账本）

> **这是唯一真相源。** 提示词和交接条都是它的视图。
> 只追加，不修改，不删除。写错了就再追加一条「补」。
> 谁写：**AI 写，你只负责粘贴。** 口令：「给我日志条目」。

---

## 一条日志的格式

```
## YYYY-MM-DD · 科目 · 章节 · 块编号 块名
- 判定: 过 x/4，卡在第 __ 条（____）
- 我的原话: "……"
- 错因: 读题 | 记混 | 没懂 | 蒙
- 材料: 教材P___（+参考书P___ / 视频链接，用了才写）
- 时长: __h__
- 下一步: 一句话
```

## 回访的写法（到期那天追加一行）

```
- 回访(11-28): 通过 → 进第 2 档（下次 12-01）
- 回访(11-28): 没通过 → 退回红块，重新 1 天
```

## 补上的写法

```
- 补(11-30): 反例补上了 —— 「咱们班所有高个子」不满足确定性
```

---

## 五条硬规矩

1. **只追加。** 历史就是历史，改了就失去"我当时到底怎么错的"这个唯一有价值的信息。
2. **错因必须四选一**：读题 / 记混 / 没懂 / 蒙。不许写"粗心""没记住"这种含糊词。
3. **必须有"我的原话"。** 到期回访要用它——三天后拿你自己的话问你，才有杀伤力。
4. **不写感悟、心情、自我评价、总结陈词。** 日志是账本，不是日记。
5. **一块一条，卡住也写一条。** 没讲通的那条比讲通的更值钱。

---

## 完整示例

```
## 2026-11-26 · 数学 · 1.1 集合的概念 · 块1/4 集合与元素的含义
- 判定: 过 3/4，卡在第 2 条（举不出反例）
- 我的原话: "元素是研究对象，集合是这些对象的总体"
- 错因: 没懂
- 材料: 教材P001
- 时长: 2h10
- 下一步: 明天先补"反例"，从这块重来

## 2026-11-26 · 数学 · 1.1 集合的概念 · 块2/4 ∈ 与 ∉
- 判定: 过 4/4
- 我的原话: "a∈A 是'a 在 A 里面'，不是'a 等于 A'"
- 错因: （无）
- 材料: 教材P001；参考书P12（方法，看完重做原题 1 道）
- 时长: 1h20
- 下一步: 排期 1 天后回访

## 2026-11-27 · 英语 · 语法 · 块1 定语从句的先行词
- 判定: 过 3/4，卡在第 3 条（变式题错 1 道）
- 我的原话: "先行词就是被从句修饰的那个名词，从句紧跟它"
- 错因: 记混（把先行词和关系词搞反）
- 材料: 教材P22
- 时长: 1h50
- 下一步: 明天补 5 道先行词判断题

## 2026-11-27 · 物理 · 运动学 · 块1 位移和路程
- 判定: 过 2/4，卡在第 4 条（说不出和速度的关系）
- 我的原话: "位移是首尾连线，路程是走的路"
- 错因: 没懂
- 材料: 教材P8
- 时长: 1h30
- 补(11-28): 关系是"位移除以时间才是平均速度，路程除以时间只是平均速率"
- 下一步: 回访时重讲这一句
```

## 每周日从日志里能算出什么

| 问题 | 从哪看 |
|---|---|
| 我这周真讲通了几块？ | 数「判定: 过 4/4」的条数 |
| 我最大的病是什么？ | 错因四类的出现次数 |
| 我总是卡在第几条？ | 卡点分布（多数卡在第 2 条=举不出例子，说明理解停在表面） |
| 哪些块拖了三周还没通？ | 同一块名重复出现且判定没变 |
| 参考书/B站到底有没有用？ | 「材料」字段里它们的出现频率 vs 对应块的判定 |

**最后一条特别重要**：如果某个材料出现很多次但对应块一直没通，说明它对你无效，砍掉。
