# 日课表 · v2（单科主推 + 每日保养）

> 2026-11-25 v2。参数：**上午 2 + 下午 2 + 晚上 1 = 5 小时**；**主推层一天只推一科**；**讲通才走**；数学最高优先级。
> v1 的错误：5 天全推数学（25 小时），其他科会荒。v2 改成「主推 4 小时 + 保养 1 小时」，且按学科性质分块。

---

## 〇、为什么"一天一科"只对一半学科成立

| 学科性质 | 代表 | 怎么排 | 为什么 |
|---|---|---|---|
| **概念型**（需要连续推理、深度） | 数学、物理、化学 | **一天一科，整块推 4 小时** | 切换科目有 10–15 分钟重启成本；推理需要连着的上下文；隔一夜反而有助于想通 |
| **记忆型**（需要高频、不能断） | 英语单词、语文古诗文 | **每天薄薄一层，绝不整块** | 遗忘曲线要的是频率，不是深度。一周集中 5 小时不如每天 20 分钟 |

**所以"换脑子"不靠换科目，靠换活动类型**：读 → 做 → 讲 → 写，本来就在日课表里轮着走。

---

## 一、周表（主推层）

| 星期 | 主推（4 小时） | 说明 |
|---|---|---|
| 周一 | **数学** | 一周之始，脑子最清醒 |
| 周二 | **数学** | 连着两天，把一节推到底 |
| 周三 | **英语** | 专题深推（语法 / 阅读 / 写作各一块），不是背单词 |
| 周四 | **数学** | 回主科 |
| 周五 | **物理 / 化学**（隔周轮换） | 理科不能只靠数学 |
| 周六 | **弹性日** | 补本周没讲通的块 / 概念缺口专项 / 或第二个英语日 |
| 周日 | **不推新内容** | 2 小时：复盘 + 30 分钟限时测 + 其余休息 |

**数学 = 3 个主推日（12 小时/周），占主推时间 60%。** 这就是"最高优先级"的具体样子，不是嘴上说说。
**其他科不再荒**：英语每天有保养层，物理化学每周一天 + 保养层里的回顾。

## 二、主推日的一天（5 小时）

### 上午 2 小时（08:30–10:30）· 新学段

| 时间 | 时长 | 干什么 |
|---|---|---|
| 08:30–08:38 | 8′ | 开工：计时 40′、手机放侧面、写下"今天过哪一块" |
| 08:38–08:58 | 20′ | **到期回访**：遮住答案复述前几天的话，讲不出标红 |
| 08:58–09:10 | 12′ | 定位：拍页 / 圈块 / 看这节结构 |
| 09:10–09:50 | 40′ | **自读 + 讲给 AI 听，被追问三层**（凭什么 / 举例 / 反例） |
| 09:50–10:00 | 10′ | 起身离开桌子 |
| 10:00–10:30 | 30′ | 例题：先自己做，卡住只记"卡在哪一步"，不看答案 |

### 下午 2 小时（14:00–16:00）· 练 + 验

| 时间 | 时长 | 干什么 |
|---|---|---|
| 14:00–14:05 | 5′ | 回顾上午卡点，列 3 个待验点 |
| 14:05–14:45 | 40′ | 限时做题 5–8 道 |
| 14:45–15:05 | 20′ | **错因归因**（读题 / 记混 / 没懂 / 蒙）+ 回原文补漏 |
| 15:05–15:35 | 30′ | **关书复述**，AI 只当听众 |
| 15:35–15:55 | 20′ | **变式题 / 参考书方法**（见第四节规则） |
| 15:55–16:00 | 5′ | 对照四条标准判定"过了几条" |

### 晚上 1 小时（19:30–20:30）· 保养层（每天都做，不分主科是哪科）

| 时间 | 时长 | 干什么 |
|---|---|---|
| 19:30–19:50 | 20′ | **英语**：单词 15′（新词 10 + 复习旧词 5）+ 朗读 5′ |
| 19:50–20:10 | 20′ | **语文**：古诗文默写 / 背诵（一天一篇，滚动重复） |
| 20:10–20:20 | 10′ | 出今日清单：讲通了什么 / 卡在哪 / 明天第一件事 |
| 20:20–20:30 | 10′ | 存档 + 写下明天第一格 |

**20:30 硬停。** 晚上不做新东西。

## 三、一块算"讲通"的四条（少一条就是没过）

1. **关书复述** 5 句，逻辑自洽（不是背）
2. **能举例 + 能举反例**（自己编的）
3. **做对 3 道同类型题**，含 1 道变式
4. **能说出它跟上一块凭什么连着**

判定写成一句话：`这一块：过了 1/2/3/4 条，卡在第 __ 条`。

---

## 四、三种材料怎么排（教材 / 参考书 / B 站课）

你的目标是：**把参考书的例题和知识点学一遍，沉淀到网站。** 那这三种材料必须是主从关系，不能平起平坐。

| 材料 | 角色 | 什么时候用 | 硬规则 |
|---|---|---|---|
| **教材** | 唯一的地基 | 上午定位、自读 | 事实以教材为准；参考书和教材冲突时，以教材为准并记录冲突 |
| **参考书** | 方法库，不是第二本教材 | **只放下午 15:35–15:55 那一格** | 先自己做变式题，做不出来**才**翻方法；看完必须**立刻把原题重做一遍** |
| **B 站课** | 卡住时的急救包 | **只在"概念缺口"上调用**，或周六弹性日的 20 分钟 | **不许按课程目录刷课**。只有某一块卡住超过 2 个时段，才允许去搜那一块的课；看完立刻回来讲给我听 |

**为什么这么硬**：看课是最舒服的"假学习"——它是被动接收，会让你感觉很好但什么都没发生。**没有卡点的课，一律不看。**

**参考书方法的价值**：它教的是"解题套路"，套路必须先失败过再学，否则记不住也用不上。

---

## 五、沉淀到网站的是什么

不是教材搬运。只有四类东西进网站：

| 类型 | 内容 | 频率 |
|---|---|---|
| **讲通存证** | 每块一句"你的原话" + 过了几条 + 日期 | 每块 |
| **概念缺口** | "我卡在 ______"，以及后来怎么补上的 | 每次卡住 |
| **错因统计** | 读题 / 记混 / 没懂 / 蒙，四类的累计次数 | 每周日汇总 |
| **方法卡** | 参考书里真正用上过的套路（含一道原题） | 用一次记一张 |

**网站的价值 = 这四类东西的累积。** 教材原文永远不进网站（那不是你的东西，网上到处都是）。

## 六、卡住了怎么办

| 情况 | 处理 |
|---|---|
| 同一块 > 2 个时段（约 100 分钟）仍不过 | 停。换到复习/做题，今天不再碰 |
| 讲不通、知道缺前置 | 降级三步：① 回上一节找前置 ② 换材料（换讲法/找视频/换本书） ③ 记入概念缺口 |
| 连续 3 天同一块不通 | 判定前置有洞，整天改成补前置，不许硬啃 |
| 状态差 | 只保上午"讲给我听"那一格 + 晚间保养层，其余降为空转复习 |

## 七、周日 2 小时

| 时间 | 干什么 |
|---|---|
| 09:00–09:30 | 30 分钟限时测（范围 = 这周讲通的块） |
| 09:30–10:00 | 复盘：错因统计 + 概念缺口清单 + 下周主推安排 |
| 10:00–10:30 | 把这周清单录进网站（唯一开网站的时间） |
| 其余 | **休息，不推新内容** |

## 八、一天里"跟 AI 说话"占多少

| 类型 | 时长 | 占比 |
|---|---|---|
| 讲给 AI 听 / 被追问 / 关书复述 | 约 70–100 分钟 | 25–30% |
| 自己读、做题、写归因 | 约 140 分钟 | 45% |
| 有效期回访、保养层、记账、休息 | 约 100 分钟 | 35% |

我负责"必须开口讲"那一段，其余是你自己动手。**如果我占满 5 小时，你就是在听讲，不是在学。**

## 一句话版

> 主推 4 小时给一科（概念型整块推）＋ 晚上 1 小时保养（英语 20′、古诗文 20′、记账 20′）。
> 周一二四数学、周三英语、周五物理化学、周六弹性、周日复盘。
> 参考书只在下午变式题那格，B 站课只在卡住时看。**讲不通不走，卡过 100 分钟就停。**
