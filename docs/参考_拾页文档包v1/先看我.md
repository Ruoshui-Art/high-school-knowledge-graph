# 先看我 · 这份文档包怎么用

> 收录于 2026-11-25，来自另一个 Agent 的学习机制设计。

## 它的定位：参考，不是规矩

这套文档写得认真，很多判断是对的（账本分裂的诊断、错因四选一、用"自己的原话"回访）。**但它不是你必须照做的日程表。**

最要紧的一句话：**它把"一个人自学没人接话"这个问题，解成了"发一堆表格让你自己填"。表格不会接话。**

所以这里面的「日课表」「5 小时」「周表」「到期档位」——**都只是可选参考**。你不必每天打卡 5 小时，不必按周一二四数学的表格走。

## 真正起作用的机制（网站已经做进去了）

学习发生在**你和 AI 的对话里**：你讲、它追问三层（凭什么 / 举例 / 反例）、你卡住它就停在那、隔天拿你自己的话反过来问你。

网站只做三件事：
1. **工作台**：你亲手把原文拆成节点，起名、连线、写理由
2. **留下原话**：点亮"真懂"前，必须写下你自己的一句话——这是隔天回访的弹药
3. **到期反问**：隔天/隔几天，网站把那句话摆出来，你自己判讲不讲得出

这三件事在 `workbench.html` 和 `review.html` 里。文档是它们的说明书，不是它们的主人。

## 各文件是什么

| 文件 | 价值 |
|---|---|
| `01_提示词.md` | **值得用**。开新对话时粘一次，把 AI 从"讲给你听"强制改成"追问你" |
| `03_日志.md` | **值得用**。只追加、错因四选一、必须有原话——账本思路对 |
| `02_交接条.md` | 换 AI 时用，避免重新解释背景 |
| `交流摘要_20261125.md` | 当天决策记录，回头看用 |
| `日课表.md` / `学习流程卡.md` | **仅参考**。时间格、频次别当硬指标 |

## 一条边界

文档里所有结论都要先看证据再用。它自己都记着一条教训："任何结论先看证据再下。" 这条也送给你。
